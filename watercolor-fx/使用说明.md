# watercolor-fx — 流体水彩动效组件包

把 davidwhyte.com/experience 同款的「流体光标 + 水彩显影 + 点击墨花 + 自定义光标」
做成的可复用组件，外加一个让整页滚动贯通的 SmoothFlow 模块。
零依赖、纯 WebGL、原创实现，可用于任何网页（含 React / Vue / 原生 HTML）。

## 文件清单

| 文件 | 作用 | 何时引入 |
|---|---|---|
| `watercolor-fluid.js` | 核心引擎（流体模拟 + 渲染 + 光标） | 必须 |
| `watercolor-attach.js` | 一行挂载器（自动建画布/暂停/卸载） | 推荐 |
| `smooth-flow.js` | 惯性滚动 + 锚点缓动 + 背景视差 | 可选 |
| `demo.html` | 独立演示页（双击即看） | — |

## 一分钟上手

```html
<!-- 1. 任何页面，三行代码 -->
<script src="watercolor-fx/watercolor-fluid.js"></script>
<script src="watercolor-fx/watercolor-attach.js"></script>
<script>
  // 方式 A：全页墨水拖尾（不影响页面任何交互）
  WatercolorAttach.overlay({ PALETTE: ['#8b3a1f', '#d4a574'] });

  // 方式 B：某个区块内"光标划过显影出图片"
  WatercolorAttach.veil('.hero', { image: 'photo.jpg' });
</script>
```

`veil()` 会自动：把容器设为 relative、创建铺满的画布（pointer-events:none，
不挡点击）、容器离开视口时暂停模拟省性能。返回的实例有 `.detach()` 可整体卸载。

## 三种渲染模式（MODE）

| MODE | 画面 | 典型用法 |
|---|---|---|
| `'paint'`（引擎默认） | 不透明纸面，墨水晕开处显出图片 | 独立体验页/开屏，davidwhyte 原版形态 |
| `'ink'` | 透明画布，只有彩色墨水拖尾 | `overlay()` 默认，叠加在任意页面 |
| `'reveal'` | 透明画布，划过处"显影"出清晰图片 | `veil()` 默认，叠在模糊/暗蒙版底图上 |

## 在框架里使用

### React（山夏 index.html 里 FluidVeil 就是这个写法）

```jsx
function FluidVeil({ src, primary = false }) {
  const ref = React.useRef(null);
  React.useEffect(() => {
    if (!window.WatercolorFX || !ref.current) return;
    const fx = WatercolorFX.init({
      canvas: ref.current, image: src, MODE: 'reveal',
      CUSTOM_CURSOR: primary,
    });
    const ob = new IntersectionObserver(
      es => es.forEach(e => (e.isIntersecting ? fx.resume() : fx.pause())),
      { threshold: 0.02 }
    );
    if (fx.supported) ob.observe(ref.current);
    return () => { ob.disconnect(); fx.destroy(); };
  }, [src, primary]);
  return <canvas ref={ref} style={{ position:'absolute', inset:0, width:'100%', height:'100%', zIndex:0, pointerEvents:'none' }} />;
}
```

### Vue 3

```vue
<template><div ref="host" class="hero">…</div></template>
<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue';
const host = ref(null); let fx;
onMounted(() => { [fx] = WatercolorAttach.veil(host.value, { image: '/photo.jpg' }); });
onBeforeUnmount(() => fx && fx.detach());
</script>
```

## 引擎 API（WatercolorFX.init 返回的实例）

| 方法 | 说明 |
|---|---|
| `setImage(srcOrElement)` | 换图（URL / Image / Canvas / dataURL） |
| `burst(clientX, clientY)` | 在屏幕坐标手动触发墨花爆开 |
| `splatAt(clientX, clientY, dx, dy)` | 手动注一笔墨 |
| `clear()` | 清空墨水，画面淡回 |
| `pause()` / `resume()` | 暂停 / 恢复模拟 |
| `destroy()` | 销毁（移除监听与 GL 资源） |

## 常用配置（传给 init / veil / overlay 均可）

| 配置 | 默认 | 说明 |
|---|---|---|
| `image` | — | 被显影的图片 |
| `PALETTE` | 5 色水彩板 | 墨色数组，随时间缓慢轮换 |
| `SPLAT_RADIUS` / `SPLAT_FORCE` | 0.21 / 5600 | 笔刷大小 / 力度 |
| `DENSITY_DISSIPATION` | 0.55 | 墨水消散速度（小=久留） |
| `CURL` | 6 | 涡旋卷曲感 |
| `CLICK_SPLATS` / `CLICK_FORCE` / `CLICK_RADIUS` | 16 / 900 / 3.2 | 点击爆开形态 |
| `REVEAL_LOW` / `REVEAL_HIGH` | 0.05 / 0.6 | 墨量→显影的映射区间 |
| `EDGE_DARKEN` / `GRAIN` / `IMAGE_DISTORT` | 0.22 / 0.5 / 1.6 | 水彩边缘积色 / 纸纹 / 渗开扭曲 |
| `CUSTOM_CURSOR` | true | 圆点+延迟圆环光标（触屏自动禁用；多实例时只开一个） |
| `CURSOR_HOVER_SELECTOR` | `a, button, [data-cursor]` | 悬停放大光标环的元素 |
| `IGNORE_CLICK_SELECTOR` | 表单/链接等 | 点击这些元素不触发墨花 |
| `SIM_RESOLUTION` / `DYE_RESOLUTION` | 144 / 1024 | 性能档位（移动端建议 96 / 512） |

## SmoothFlow（页面贯通模块）

引入即生效：惯性平滑滚动（wheel 阻尼）、`a[href^="#"]` 锚点缓动、
`.photo-stage .photo-bg` 视差。配置在引入前覆盖：

```html
<script>window.SMOOTH_FLOW_CONFIG = { ease: 0.12, anchorOffset: 80, parallaxSection: '.my-section', parallaxTarget: '.my-bg', parallaxRange: 48 };</script>
<script src="watercolor-fx/smooth-flow.js"></script>
```

视差背景的 CSS 需要消费 `--py` 变量，并上下出血避免露边：

```css
.my-bg { inset: -12vh 0; transform: translate3d(0, var(--py, 0), 0) scale(1.04); }
```

代码里随时可调用 `SmoothFlow.to(y)` 平滑滚到任意位置。
自动尊重 `prefers-reduced-motion`（无障碍降级为原生滚动）。

## 常见问题

**图片不显影、console 提示 image not usable？**
跨域图片需要服务器返回 CORS 头（unsplash 可以；不支持的图床会自动降级为纯墨流）。
本地图片用相对路径、dataURL、或同源服务即可，最稳。

**双击 html 直接打开（file://）可以吗？**
引擎和挂载器可以。但若页面本身要加载跨域资源（如 CDN 的 React），建议起本地服务：
在目录里运行 `python -m http.server 8123` 后访问 localhost:8123。

**多个区块各挂一层会卡吗？**
不会。`veil()` 自带视口暂停，离屏的模拟是停着的；同屏一般最多 1–2 个实例在跑。

**怎么完全卸载？**
`veil()`/`overlay()` 返回实例的 `.detach()`；React/Vue 里在卸载钩子中调用即可。
